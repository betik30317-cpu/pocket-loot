# 口袋寶箱

一款在瀏覽器裡開著就會自己打怪的可愛放置刷寶遊戲。純文字介面，用原生 HTML、CSS、JavaScript 寫成，不需要建置工具。

## 怎麼玩

角色會自動打怪，掉到的裝備放在右邊的背包。點背包裡的裝備可以看到換上後數值怎麼變，覺得比較好就按「穿上」。不想要的裝備可以分解成金幣，也可以設定自動分解的稀有度。

## 本機執行

因為使用 JavaScript 模組，需要透過網頁伺服器開啟，不能直接雙擊 index.html：

```
python3 -m http.server 8000
```

然後打開 http://localhost:8000 。
